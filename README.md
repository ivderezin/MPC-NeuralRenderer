# MPC Neural Renderer

Нейрорендеринг видео внутри Media Player Classic. Основа — форк [MPC Video Renderer](https://github.com/Aleksoid1978/VideoRenderer), GPL-3.0.

## Сборка на Windows

1. Установите Visual Studio 2022 с Desktop development with C++, MFC, ATL и Windows SDK.
2. Выполните `powershell -ExecutionPolicy Bypass -File tools/Fetch-NgxSdk.ps1`. Скрипт загружает закреплённые заголовки и статическую библиотеку публичного NVIDIA DLSS SDK; условия NVIDIA доступны в его репозитории.
3. Выполните `build_mpcvr.cmd` либо откройте `MpcVideoRenderer.sln` и соберите `Release | x64`.
4. Результат: `_bin/Filter_x64/nvngx.dll_MpcNeuralRenderer64.ax`.

## Подключение

1. Скопируйте `nvngx_dlssnr.dll` рядом с `.ax`. Модель NVIDIA не распространяется с проектом.
2. Зарегистрируйте рендерер из терминала администратора: `regsvr32 "полный путь к nvngx.dll_MpcNeuralRenderer64.ax"`.
3. В MPC-HC откройте **Options → External Filters → Add Filter**, выберите **MPC Neural Renderer** и установите **Prefer**. Если он не появляется в списке, используйте **Browse** и укажите `.ax`.
   Это отдельный DirectShow-рендерер с собственным CLSID. Установка не изменяет регистрацию штатного MPC Video Renderer и настройки выбора вывода плеера. Встроенный пункт «MPC Video Renderer» продолжает выбирать штатный компонент; отдельный пункт в этом списке сам по себе не добавляется.
4. В свойствах рендерера включите Direct3D 11 и Neural rendering, выберите интенсивность, нажмите Apply.
5. Откройте карту захвата или видео. Включите Show statistics для просмотра состояния NR.

Чтобы отключить дополнительный рендерер, снимите его флажок в **External Filters** и заново откройте видео / захват. Плеер снова построит граф с выбранным штатным рендерером.

Удаление: `regsvr32 /u "полный путь к nvngx.dll_MpcNeuralRenderer64.ax"`. Эта команда снимает только регистрацию MPC Neural Renderer.

## Ограничения первой версии

- Только Windows x64 и SDR с 8-битным RGB-буфером вывода. HDR и стереопреобразование обходят нейрообработку.
- Оценка движения по изображению: блочный поиск на GPU, current → previous в пикселях. Это приближение, а не векторы игрового движка; поиск ограничен ±16 пикселями за кадр.
- Данные о глубине отсутствуют; используется нулевая текстура.
- Повторный вывод одного кадра использует сохранённый результат. Перемотка, длительный разрыв и изменение размера сбрасывают историю.
- Ошибка загрузки или NGX отключает обработку до изменения настроек / повторного открытия. Исходное видео продолжает выводиться; причина видна в статистике.
- Используется NGX Feature 18. Имя `.ax` содержит `nvngx.dll` для совместимости проверки имени вызывающего модуля в модели 310.8.0.0. Патчи памяти и перехваты функций для этого не используются.

## Устройство

`Source/NeuralRendering` содержит настройки, политику истории, вычисление движения и NGX / D3D12-интеграцию. `CDX11VideoProcessor` вызывает этот модуль после видеопроцессинга и до субтитров / OSD. Все операции выполняются в процессе плеера.

Происхождение исходников и лицензии: [docs/upstream.md](docs/upstream.md). Исходная документация: [docs/upstream-readme.md](docs/upstream-readme.md).

## Проверки

`tools\Test.cmd` запускает тесты истории кадров и тесты compute-шейдеров через D3D11 WARP: направление движения, неподвижный кадр, сброс истории, обрезка области видео. Модель NVIDIA для них не нужна. Полная сборка и эти тесты также настроены в GitHub Actions.
