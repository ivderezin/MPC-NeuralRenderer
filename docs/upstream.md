# Source provenance

For the scope and host differences of the EchoStorm port, see [the implementation comparison](echo-storm-comparison.md). The branch now includes the native EchoFG synthesizer, adapted post-FG protection, independent NR delta composition, exact duplicate-batch suppression and display-aware pacing. Applying FlowFix to vendor FG guidance and extending the FSR guard to DLSS MFG fractions are MPC-specific adaptations.

- MPC Video Renderer: https://github.com/Aleksoid1978/VideoRenderer, revision `369af64d001b540f4f7e634fd46189b93ffb4b7d`, GPL-3.0 (see LICENSE.txt; original file notices retained).
- BaseClasses: https://github.com/v0lt/BaseClasses, revision `de6f4a9971efcd4f53b2ef94552914c5af25c638`, vendored under external/BaseClasses; original notices retained.
- MinHook: https://github.com/TsudaKageyu/minhook, revision `c3fcafdc10146beb5919319d0683e44e3c30d537`, vendored under external/minhook; see its LICENSE.txt.
- NVIDIA SDK headers: downloaded separately from NVIDIA/DLSS, revision `9981c6350dc58c0ce21f024fd65e31e851c31689`. Not included in source control. NVIDIA terms apply.

The project uses independent renderer and property-page CLSIDs. The upstream IVideoRenderer ABI and interface IIDs remain unchanged for binary compatibility. All settings live under HKCU\Software\MPC Neural Renderer, independently of the upstream renderer. Window class and parent-window property names are also namespaced.

No MPC player settings are changed during registration. Playback with this independent CLSID still needs Windows validation.

Feature 18 contract reference (no source copied): https://github.com/bmitch87/DLSS5VKLayer/blob/main/extracted_pipeline_notes.md. The DLL call route is version-sensitive and must be validated on Windows.

DLSS SR and standalone MFG use NVIDIA's pinned `nvsdk_ngx_helpers_d3d.h` and `nvsdk_ngx_helpers_dlssg_d3d.h`. The host owns presentation and frame pacing; no Streamline proxy swap chain or player-DLL replacement is installed.

The BaseClasses `CCritSec` wrapper has a non-blocking `TryLock` addition for timer-driven presentation on the player's window thread. Class layout and existing locking behavior are unchanged.

FSR headers and redistributable runtimes are fetched from GPUOpen-LibrariesAndSDKs/FidelityFX-SDK, revision `60f4ea81909200d8542eca14dccb2628b763a9a3`. XeSS SR / FG and XeLL are fetched from intel/xess, revision `de0fb9c1c510661c571164e1418ceca8101dab69`. Exact URLs and SHA-256 hashes are recorded in `tools/vendor-sdks.json`; SDK files remain outside source control. AMD and Intel license files accompany the Windows package. FSR selects the cross-vendor FSR 3.1 providers explicitly.

FSR FG uses the public standalone dispatch API with `FFX_FRAMEGENERATION_FLAG_NO_SWAPCHAIN_CONTEXT_NOTIFY`. XeSS FG uses Intel's D3D12 proxy swap chain and XeLL, while the existing D3D11 video renderer draws into an offscreen surface. Shared NT-handle textures and fences transfer the completed frame and estimated guidance on the same GPU. The two frame-generation backends are mutually exclusive; selecting XeSS never calls the standalone NGX / FSR generator.

EchoStorm motion estimation: `Source/NeuralRendering/EchoMotionShaders.h` adapts the luma pyramid, global shift, block search, vector median and per-pixel refinement from [Echo-Storm/ls-addon-manager](https://github.com/Echo-Storm/ls-addon-manager/blob/8d3eac351d42480326290b0f8965127a630b44f2/addons/DLSS5NR01/src/engine/flow_estimator.cpp), revision `8d3eac351d42480326290b0f8965127a630b44f2`. Copyright (c) 2026 Echo-Storm and andreiday, MIT; the complete notice is retained in `Source/NeuralRendering/EchoStorm-LICENSE.txt` and copied into Windows packages. This earlier motion host is an independent D3D11 adaptation; its SR guidance does not expose the optional shape-cost mode. The new EchoFG and NR backends separately use the original D3D12 modules listed below. Inputs use this renderer's existing SDR proxy. EchoStorm is the default for new/missing/invalid settings; an explicitly saved Fast selection is preserved. The full motion path adds local-consensus repair from the same revision of `flow_fix.cpp` (`MotionRepairShaders.h`, independent D3D11 host `MotionRepair.cpp`): tile votes, flat/repeating-patch decisions, and a separate repaired field. The corrected EchoStorm field is shared by NR and DLSS/FSR/XeSS SR/FG; Fast retains its original NR/SR field and gets repair before FG. At 4K the voting bins scale with width because this host retains full-resolution analysis. Matching distrust stays separate from fast-motion SR confidence so camera votes are not suppressed. DLSS SR receives bias-current-colour, FSR receives reactive, and XeSS receives responsive-pixel masks. `Upscaling/MotionAdaptiveShaders.h` adapts the Catmull-Rom/lean pass from `sr_engine.cpp` under the same MIT notice, using this renderer's SDR proxy and range-clamped spatial reconstruction in unreliable/fast areas for every SR provider. The SR adaptation does not include the entire separate SR host or its optional EASU/edge-smoothing modes.


Native EchoStorm pipeline: `Source/EchoStorm/{engine,addon,forwarder}` vendors `own_synth`, `flow_estimator`, `flow_fix`, `nr_engine`, `nr_shaders`, `hdr_hlsl`, `shader_cache`, `ngx_users`, `ngx_paths`, `dlaa_model`, `bridge`, `compose11`, `gpu_timer11`, `auto_quality`, `nr_forwarder` and `nr_api` from the same pinned revision, under [the upstream MIT license](../Source/EchoStorm/EchoStorm-LICENSE.txt). Source notices remain in every imported file. Host adaptations include namespaced paths/NGX ownership, standalone statically linked adapter DLL, project NGX identity, BGRA render-target fallback, image rotation/flip, and separate MPC queue/timestamp handling. `FrameGeneration/EchoGuardShaders.h` adapts the same revision's `fg_engine.cpp` guard with GPU mean motion, input/output vector scaling and arbitrary MFG fractions. `EchoPresentationClock.h` implements the host timing principles of `framegen11.cpp`; `ExactInputRepeat.h` independently implements a full RGB comparison and suppresses publication after the existing completion fence. The latter does not claim the upstream experimental SR work-skip policy.

Follow-up after user testing: EchoStorm-mode DLSS FG now uses the native final-frame estimator/FlowFix host in motion-only mode, at output resolution, instead of the earlier shared D3D11 pre-NR/SR field. Independent composition uses shared delta alpha for source-proxy luminance and validates it against the presented frame; age and out-of-bounds projections also suppress the delta. These safeguards are MPC adaptations, not upstream LSFG bidirectional-flow guards.

All active EchoStorm paths now use the native D3D12 estimator and FlowFix host: sequential NR, all SR providers, standalone vendor FG, and the separate XeSS FG presenter. The older D3D11 motion adaptation remains available only as regression/reference source. Shared NR/SR guidance exports preserve distrust and fast-motion masks; after-upscale NR vectors scale to output pixels. Stage-specific histories remain separate because the inputs before and after processing differ. Fast block matching retains its own D3D11 path.
